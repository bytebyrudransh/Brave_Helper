# V3.1 — Feature Batch ✅ COMPLETE

## Feature A — Image Upload for Vision ✅
- Added 📎 attach button next to the chat input
- File picker accepts `.png`, `.jpg`, `.webp`
- Image read as base64 via `FileReader`
- Sent to `llava:7b` through existing `streamVision()` — backend already done
- Image never leaves localhost

## Feature B — CSV Import for Vault ✅
- Added **"CSV"** import button in the Vault tab header
- Parses standard password manager CSV exports (Chrome/Firefox/Bitwarden format: `name, url, username, password`)
- Preview count before importing ("Found 127 entries — Import all?")
- Handles quoted CSV fields with commas inside them
- Encrypts and bulk-saves all entries to the vault in one go
- No AI model needed — pure CSV parsing

## Feature C — Vault Search ✅
- Added **search/filter bar** at the top of the Vault tab
- Type to instantly filter entries by URL, username, site name, or email
- Shows count of matching logins
- Clear button to reset search
- No AI model needed — simple text matching

## Feature D — Emergency Kill Button 🔴 ✅
- Small red power icon button in the header (next to refresh)
- On click:
  - Stops all running model inference (abort controller)
  - Locks the vault immediately (if unlocked)
  - Clears current chat
  - Returns to Research mode (default safe state)
  - Resets to chat tab
- One-tap panic button — everything resets to locked-down safe state

## Feature E — Fresh Start on Open ✅
- Every time the side panel opens, starts with a clean chat
- Removed the "restore last session" behavior on init
- Previous sessions are still saved in History tab — user can go back manually
- Default view is always the clean quick-suggestions screen

## Feature F — Smart Memory (LLM-Extracted Facts) ✅
- Created `src/lib/memory.ts` module with:
  - IndexedDB-backed fact storage (key/value pairs)
  - Upsert, delete, load operations
  - `formatMemoryPrompt()` — injects facts into system prompt
  - `buildExtractionPrompt()` — for future auto-extraction
- Memory facts loaded on init and injected into every system prompt
- Facts persist across sessions
- Future: auto-extract facts from conversations

## Feature G — Professional Tone ✅
- Updated all 5 system prompts (`project-models/*.md`) to:
  - Address user as "Sir" when appropriate
  - Use professional, respectful tone
  - Be concise but thorough
  - Avoid casual filler words

## Feature H — UI Cleanup ✅
- Removed "NEURAL ARCHITECTURE V3.0 — LOCAL ENVIRONMENT" footer
- Removed SECURE / OFFLINE / 8K ACTIVE status indicators
- Clean input area with just text box, attach, clear, and send
