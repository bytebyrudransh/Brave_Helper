# V4.0 — Intelligent Auto-Router ✅ COMPLETE

## The Big Change

Replaced manual model switching with an **AI Manager/Router**.

**Before (V3.1):** The user picks a model tier via dropdown or `/fast`, `/balanced`, `/smart`, `/code` commands. Wrong model → wrong results or wasted compute.

**After (V4.0):** A single `⚡ AUTO — AI Router` mode. Every user message gets classified by the smallest/fastest model (~50 tokens, ~0.3s) which returns `{"tier":"code"}` (or fast/balanced/smart/vision). The system auto-switches to the right specialist, then runs the real inference. Zero manual intervention.

## Architecture

```
User message
    ↓
┌──────────────┐
│  Router (9B) │  ← Tiny classification: ~0.3s, 50 tokens
│  "What kind  │
│  of request  │
│  is this?"   │
└──────┬───────┘
       ↓
  {"tier": "code"}
       ↓
┌──────────────┐
│  Specialist  │  ← Full inference with the right model
│  (Coder 14B) │
└──────────────┘
       ↓
  Streamed response
```

### Routing Rules (in `router.md`)

1. Image attached → `vision` (fast path, no classification)
2. Slash commands → `fast` (fast path, no classification)
3. Code questions → `code`
4. Simple questions, greetings → `fast`
5. Multi-step reasoning → `balanced`
6. Deep analysis, essays → `smart`
7. Default fallback → `balanced`

### Fallback Chain

If classification fails (timeout, parse error, model not loaded):
→ Always returns `balanced` (safest middle ground).

If the classified tier's model isn't installed:
→ Tries `balanced` → `fast` → `smart` → `code` → whatever is available.

## UI Changes

- **Model dropdown** now has `⚡ AUTO — AI Router` as the first/default option
- Selecting any specific model **disables** auto mode (manual override)
- `/auto` command re-enables auto mode
- Assistant label shows `AUTO → CODE` or `AUTO → SMART` etc. when routing
- Audit log shows router decisions with ⚡ icon

## User Commands

| Command | Effect |
|---------|--------|
| `/auto` | Re-enable auto routing |
| `/fast` | Lock to Fast (disables auto) |
| `/balanced` | Lock to Balanced (disables auto) |
| `/smart` | Lock to Smart (disables auto) |
| `/code` | Lock to Code (disables auto) |
